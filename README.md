Proyecto de **Introducción a la Programación, tercer momento**. Es un portal web de gestión académica para organizar y consultar los procesos de estudiantes, docentes y personal administrativo de una institución educativa.

El proyecto está construido con **HTML semántico y CSS puro**, con una interfaz clara, adaptable y fácil de recorrer. Con acceso por perfiles y módulos académicos relacionados entre sí.

## Funcionalidades

- **Acceso por perfil:** permite elegir entre el espacio de usuario y el panel administrativo.
- **Registro:** incluye el formulario de creación de cuenta con sus campos de datos personales y de acceso.
- **Espacio de usuario:** muestra el perfil y las consultas académicas: matrículas, calificaciones, asistencia y horario.
- **Administración académica:** ofrece listados y formularios para estudiantes y docentes, además de matrículas, inscripciones, notas y asistencia.
- **Navegación adaptable:** usa una barra lateral, tarjetas, tablas y formularios que se ajustan a pantallas de escritorio y móviles.

## Diseño y estructura

La interfaz usa un tema claro con tonos suaves y utilizando un mismo css para todo el diseño visual de toda la web.

Estructura del proyecto:

- `index.html`: bienvenida y presentación institucional.
- `Frontend/Auth/`: acceso y registro.
- `Frontend/Pages/`: espacio de usuario y consultas académicas.
- `Frontend/Admin/`: administración y configuración académica.
- `Frontend/Styles/style.css`: estilos compartidos y diseño adaptable.

## Tecnologías

- **HTML5** para la estructura y el contenido.
- **CSS3** para la presentación visual y el diseño adaptable.
- **JavaScript** solo para la redirección del formulario de acceso.

No se utilizan frameworks ni dependencias que haya que instalar.

## Alcance actual

Esta versión permite visualizar y explorar los diferentes módulos del sistema mediante el acceso por perfiles de usuario. Actualmente, la información de las tablas y los formularios es de ejemplo, ya que aún no se cuenta con una conexión al backend ni a la base de datos.

## Cómo visualizarlo

1. Descarga o clona el repositorio.
2. Abre `index.html` en un navegador.
3. Usa los enlaces de navegación para explorar el portal y sus módulos.
